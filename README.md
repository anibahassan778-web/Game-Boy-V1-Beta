# 🎮 Game Boy V1 Beta

A modern Game Boy & Game Boy Color emulator for Android.

## Features

- Game Boy (DMG) support
- Game Boy Color (CGB) support
- Fast emulation
- Touch controls
- Save & Load states
- Audio support
- Android optimized

## Built With

- Kotlin
- Android Studio
- Gradle
